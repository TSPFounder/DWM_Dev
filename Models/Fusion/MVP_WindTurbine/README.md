# Wind turbine rotor — Fusion parametric build script

Builds the rotor assembly from `Wind_Turbine_BOM.xlsx` as Fusion geometry:
a 58.5 m blade lofted through 20 airfoil stations, internal spar caps and
shear webs, hub, spinner, and root bolt circle.

## Install and run

1. Fusion → **Utilities** tab → **ADD-INS** → **Scripts and Add-Ins** (or `Shift+S`)
2. **Scripts** → green **+** → **Create New Script**
3. Replace the generated `.py` with `WindTurbineBlade.py`, keeping Fusion's
   folder/file naming convention (`MyScript/MyScript.py` — the file must match
   its folder name)
4. Select it → **Run**

Everything is driven by the `CONFIG` dict at the top of the file.

## What gets built

| Component | BOM | How |
|---|---|---|
| Aeroshell | 1100 | Loft through 20 station profiles |
| Spar caps (upper/lower) | 1110 | Loft through rectangular sections inside the skin |
| Shear webs (fore/aft) | 1120 | Loft, spanning surface to surface |
| Hub | 1200 | Revolve + 3 blade flanges at 120° |
| Spinner | 1400 | Revolved ogive |
| Root bolts | 1500 | Bolt circle, 24 representative (BOM says 80–120) |

Blades 2 and 3 are **occurrences of the same component**, rotated about the
rotor axis with precone applied. Edit the blade once and all three update —
that is the point of building it as an assembly rather than three bodies.

## Two things to know before running

**1. Fusion's internal unit is the centimetre**, regardless of document display
units. Every `CONFIG` value is in metres and converted once via `M2CM`. Getting
this wrong doesn't error — it silently builds a blade 100× too small.

**2. "Parametric" has a boundary here.** The hub, spinner and bolt circle are
published as Fusion user parameters and rebuild from the Parameters dialog. The
blade loft **cannot** — its spline points are computed by the script and baked
into sketches. To change chord, twist, thickness or prebend, edit `CONFIG` and
re-run. No Fusion API makes a swept airfoil loft equation-driven.

## Airfoil sections — read this

The sections are generated by the analytic **NACA 4-digit** formula, scaled to
the BOM's thickness distribution. They are **not** the DU 00-W-401 / NACA 64-618
sections the BOM names. Those are DU-series and 6-series profiles defined by
tabulated coordinates, not closed-form equations, and inventing numbers for them
would be worse than an honest placeholder.

The result has the correct planform, twist, thickness distribution and prebend.
The section shapes are representative.

**To use real sections:** replace `airfoil_section()` — it is the only function
that needs to change. Everything downstream consumes normalised `(x/c, y/c)`
point lists in a fixed order (upper TE → LE → lower TE, open at the TE).

## Verification

Run `verify_blade_geometry.py` with ordinary Python — **no Fusion needed**:

```bash
python verify_blade_geometry.py
```

This works because the `adsk` imports in `WindTurbineBlade.py` are guarded, so
the geometry half of the file imports standalone. All 26 checks pass:

- airfoil generator reproduces requested t/c to <0.0001
- contours don't self-intersect; trailing edges blunt, not cusped
- circle and airfoil point counts match (so the root morph pairs correctly)
- planform hits the BOM's root 2.6 m / max 3.9 m at 22% / tip 0.6 m
- twist 13°→0°, t/c 1.00→0.18, prebend 0→3.0 m, all monotonic
- no derivative singularities; exactly one slope discontinuity (the max-chord
  shoulder, which is a real planform feature)
- spar caps and webs strictly inside the skin, by point-in-polygon
- skin and structure share one twist/prebend transform

**Not verified: any Fusion API call.** Those need Fusion. Expect to iterate on
API details — lofting 20 twisted sections is the step most likely to need
adjustment, and the script reports which stations succeeded rather than failing
silently.

## Two bugs this checker caught

Worth knowing, because both would have produced plausible-looking geometry:

1. **Derivative singularity at max chord.** The outboard taper used `t**0.85`,
   whose slope is *infinite* at `t=0`. Chord reached its peak with zero slope
   and left with infinite slope — a pinch in the loft at 22% span. Now linear.

2. **Spar caps on the chord line instead of the camber line.** Caps were placed
   at `±½(t/c)·c` about `y=0`, but the sections are cambered 4%, so the real
   surfaces sit at `yc ± yt`. The lower cap protruded through the skin. Now
   placed from the actual contour via `surface_y_at()`.

A third followed from fixing the second: shear webs sampled the surface only at
their centreline, and near the tip (chord ~1 m, web 40 mm) the corners still
protruded. Now sampled at both web edges.
