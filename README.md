# DWM_Dev

Dream World Maker - a systems-engineering pipeline wrapped in a game. You
travel between five communities (Mountain, Hillside, Valley, Suburbs, City),
talk to the people in each, and trade what one community makes for what
another needs.

**To download and play, see [InstallInstructions.md](InstallInstructions.md).**

Builds are published on the
[Releases page](https://github.com/TSPFounder/DWM_Dev/releases).
